## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program copies the committed `entry.png` into the output directory. It resolves the poster from its own location, clears the output directory's contents entry by entry, and is fully deterministic — no clock, no randomness, no network — so repeated runs write identical bytes.
